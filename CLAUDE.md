# Project instructions

## Git commit conventions

- Commit as the locally configured Git identity (`git config user.name` / `user.email`). Do not override the author.
- Do not add `Co-Authored-By:` trailers (including `Co-Authored-By: Claude`) to commit messages.
- Keep commit messages short, descriptive, and professional: a concise imperative subject line, with a body only when the change needs explaining.
- Do not rewrite existing commit history (no `rebase`, `amend`, `reset`, or force-push of published commits), and do not change historical author attribution.
